## 👋 À propos

Élève ingénieure en 3<sup>e</sup> année à l'**ENSI**, classée **3<sup>e</sup> de promotion**, issue des classes préparatoires (IPEIN, filière MP).
Je construis des systèmes critiques **sûrs** et **explicables** :

- 🔐 **DevSecOps** : CI/CD GitHub Actions, SAST / SCA / DAST, scan de conteneurs, IaC
- 🧠 **IA explicable** appliquée à la santé, avec des néphrologues de l'hôpital Charles-Nicolle (RIADI)
- 🏥 Réingénierie de **NephroCare**, plateforme médicale critique (Spring Boot, React, LLM local)
- 🎯 À la recherche d'un **stage de PFE** en DevSecOps / Cloud / IA
